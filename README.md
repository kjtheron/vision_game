# 👁 Vision Game

A simple browser game that helps children practice **identifying letters of the alphabet**.

Each letter slowly fades into view one pixel at a time through a blur. As soon as the child recognizes the letter, they press **Space** and type which letter they saw. The fewer pixels it took to recognize it, the higher the score — so kids are rewarded for spotting letters early.

## How to play

1. Open `vision_game.html` in any web browser (no install needed).
2. Press **Start game**.
3. Watch the letter appear pixel by pixel in the middle of the screen.
4. Hit **Space** the moment you can read it.
5. Type the letter and press **Enter**.
6. Score points based on how quickly you recognized it — then move to the next letter.

The game runs through all 26 letters, then shows your total score.

## Settings

Adjust the difficulty from the sidebar:

| Setting | What it does |
| --- | --- |
| **Reveal speed** | How fast pixels appear (2–600 px/sec). |
| **Blur amount** | How fuzzy the letter looks. |
| **Letter size** | How large the letter is drawn. |
| **Letter case** | UPPERCASE, lowercase, or Mixed (default). |
| **Order** | Random shuffle or sequential A → Z. |

Guessing is **not** case-sensitive — just type the letter.

## Requirements

Any modern web browser. That's it — the whole game is a single self-contained HTML file.
